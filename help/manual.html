Introduction

Lekh Diagram is a sketch recognition diagramming app. Using Lekh Digram you can create different kinds of diagrams for example, block digram, flow chart, UI wireframe, organizational chart etc. Lekh Diagram offers a free hand drawing mode and recognizes basic shapes that your scribble with your finger or pencil of your iPad. The details of shape recognition is provided below this this document.


Apart from recognizing basic shapes, the Lekh Diagram also offers large set of predefined library of shapes and symbols which user can add into a diagram. The shape library includes UI wireframe, flow chart, networking symbols, icons etc.


This YouTube video demonstrates the shape recognition capabilities of Lekh Diagram. This video is done with some old version of the Lekh Diagram, but all the shape recognition capabilities remain same.

Platforms

Lekh Diagram is available for iPad, iPhone and Android devices. As, the new features in the app are introduced first in iOS version then later ported to Android version, right now the Android version is behind iOS version in terms of feature set. The lacking features are mostly in the shape library.


This manual is for iOS version of the app. For the android version of the app, users are advised to look into in-app help of Lekh Diagram Android app. The concepts are same, there few UI differences.

  3. Organize diagrams. Create new, rename, duplicate and delete diagrams

  5. Export diagrams in various formats

Modes

A user can operate on canvas in three modes. The above screenshots describe how a user can change mode by clicking mode button in the UI.

  1. Drawing: In this mode user can do free hand drawing. The Lekh Diagram will recognize shapes and connections. Please note that the Lekh Diagram recognizes single stroke drawing so the user will have to draw shapes like rectangle, circle, triangle etc in single stroke. The single stroke means, once user starts drawing, the user has to finish drawing before lifting finger (or pencil) from the device. In this mode if you click a shape, it will be selected. Users can do multiple operations on a selected shape e.g. resize, move, rotate, delete etc.
  2. Selection: In this mode, dragging finger/pencil on canvas will select or multi select shapes on canvas. User can perform operations such as delete, move etc on selected shapes.
  3. Scrolling: In this mode, dragging finger/pencil on canvas will scroll the canvas.

Two finger dragging in any mode will scroll the canvas.

Context Menu

Long press on any shape
  • To Front: Make selected shape as topmost shape.
  • To Back: Move selected shape behind all other shapes.
  • Flip Horizontal: Flip selected shape horizontally.
  • Flip Vertical: Flip selected shape vertically.
Long press on empty area
  • Change input mode to selection and select all shapes.

Limitations in free version

iOS free app

In free version, you can export non lekh formats (e.g. jpg, png, svg etc) only for five times. After that you will be prompted for In App Purchase of export feature. You cannot export lekh format in free version.


Android free app

The Android version of the free app displays advertisements. To Remove advertisements, In App Purchase required.
